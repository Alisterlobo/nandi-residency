# Nandi Residency website

Plain HTML, CSS and JS. No install needed.

## Folders
- index.html  - the page
- css/style.css  - all styles
- js/  - one file per section (config.js has phone, email, social links)
- images/  - put your photos here (banner.jpg is the top banner)
- robots.txt, sitemap.xml  - for Google (replace YOURDOMAIN.in with the real domain)

## Things to edit
1. js/config.js: EMAIL, INSTAGRAM, FACEBOOK, YOUTUBE
2. images/banner.jpg: replace with a better landscape photo (1920x900, under 300 KB)
3. robots.txt and sitemap.xml: replace YOURDOMAIN.in
4. index.html: Google Maps embed, nearby landmarks, room photos, About text
